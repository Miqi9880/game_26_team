# RobotMaster 视觉组自瞄校内赛规则

## 一、基本安排

比赛共 **5组、11人**，原则上每组2人。比赛分为自由开发、正式天梯、对打适应、正式对打和技术答辩五个阶段。

| 日期           | 安排                          |
| -------------- | ----------------------------- |
| **8月22-23日** | 发布规则及提供的代码          |
| **8月24-31日** | 自由开发，允许车辆调试        |
| **9月1-3日**   | 连续三晚正式天梯，每晚约1小时 |
| **9月4日**     | 两车对打适应性训练，不计分    |
| **9月5日**     | 正式两车对打，预计2.5～3小时  |
| **9月6日**     | 技术答辩与个人评审            |

**允许使用 AI 工具及参考开源代码，但需能够在技术答辩中解释正式比赛代码的实现原理、修改内容及设计思路。**

参考资料：[上科大视觉技术方案开源](https://fcn47qghdcqf.feishu.cn/wiki/Hcw1wxTMZicx0xkinuQcKHetn5d?from=from_copylink)  [robomaster论坛](https://bbs.robomaster.com)

## 二、提供内容

**硬件：**提供机器人，相机，运算平台（orin nx super）

**相机节点：**提供现有海康相机 ROS 2 节点及相关配置文件，但不保证相机参数的准确性与适用性。需要自行进行相机标定。可以自行修改源码及曝光、增益、白平衡等参数，并自行完成调试。

**上下位机通信节点：**提供上下位机通信节点及相关消息定义，但通信结构体需自行对齐。需自行阅读代码，完成数据接收与控制指令发布。

**注：代码以github仓库形式给出，需要自行fork后由统一基线进行开发，并保留git提交记录**

## 三、正式天梯

正式天梯于 **9月1日至3日** 连续进行三次，三次成绩全部计入总分。

比赛基准距离固定为 **3米**，具体运动参数测试后确定。

每轮比赛限时 **1分钟**，每队最多使用 **50发弹丸**。车辆初始血量为 **600 HP**，每发弹丸有效命中装甲板扣除 **10 HP**。

未发射的弹丸按未命中处理；超时或超过50发的部分不计入成绩。命中数以裁判系统记录的弹丸伤害为准。

| 场景       | 每日弹量  | 三天总弹量 | 满分     |
| ---------- | --------- | ---------- | -------- |
| 原地旋转   | 50发      | 150发      | 30分     |
| 旋转＋平移 | 50发      | 150发      | 40分     |
| **合计**   | **100发** | **300发**  | **70分** |

每支队伍每天的流程如下：

| 环节                           | 时间        |
| ------------------------------ | ----------- |
| 上电、启动程序、检查并调整参数 | 3分钟       |
| 原地旋转射击                   | 1分钟       |
| 捡弹、补弹、重置血量           | 2分钟       |
| 旋转＋平移射击                 | 1分钟       |
| 捡弹、记录成绩及换队           | 2分钟       |
| **每队合计**                   | **约9分钟** |

准备期间允许跟踪靶车，但禁止发射。两个场景之间只能补充弹丸、重置血量和切换预设参数。

5支队伍每天纯比赛时间约45分钟，包含异常处理后，每晚预留约1小时。三天天梯统一使用相同的发射车、靶车、场地和运动参数。

三天结束后，按照累计命中数计算天梯成绩：

**原地旋转得分＝三天累计命中数÷150×30**

**旋转＋平移得分＝三天累计命中数÷150×40**

**天梯得分＝原地旋转得分＋旋转＋平移得分**

每天公布当日命中数、当日得分和累计排名，但不根据名次额外加分。

## 四、正式两车对打

5支队伍采用单循环赛，每支队伍分别与其他4支队伍对打一次，共进行：

**5×4÷2＝10场对局**

### 对阵安排

| 轮次  | 第一场     | 第二场     | 轮空队伍 |
| ----- | ---------- | ---------- | -------- |
| 第1轮 | A队 vs B队 | C队 vs D队 | E队      |
| 第2轮 | A队 vs C队 | D队 vs E队 | B队      |
| 第3轮 | A队 vs D队 | B队 vs E队 | C队      |
| 第4轮 | A队 vs E队 | B队 vs C队 | D队      |
| 第5轮 | B队 vs D队 | C队 vs E队 | A队      |

现场只有两台比赛车辆，因此同一轮的两场对局依次进行。

### 单场对局流程

每场对局包含两个回合。以A队对阵B队为例：

| 回合     | A队                     | B队                     |
| -------- | ----------------------- | ----------------------- |
| 第一回合 | 使用1号车及对应场地位置 | 使用2号车及对应场地位置 |
| 第二回合 | 使用2号车及对应场地位置 | 使用1号车及对应场地位置 |

第二回合双方交换车辆和场地位置，以减少车辆性能及场地差异对比赛结果的影响。

每个回合只记录命中数，不单独判断胜负。两个回合结束后，将双方各自的命中数相加：

- 两回合累计命中数较高的一方获胜；
- 两回合累计命中数相同则为平局。

## 五、对打计分

对打满分 **30分**，由命中表现和对局胜负两部分组成。车辆初始血量为 **200 HP**，每发弹丸有效命中装甲板扣除 **10 HP**。

**命中表现20分：**

每队共进行8个回合。

**命中表现分＝8个回合累计命中数÷400×20**

**胜负表现10分：**

每场获胜得3个对局积分，平局得1分，失败得0分。每队参加4场，最高获得12个对局积分。

**胜负表现分＝对局积分÷12×10**

**对打得分＝命中表现分＋胜负表现分**

命中表现分反映队伍的实际准确率，胜负表现分用于体现对打中的稳定发挥。

## 六、最终排名

比赛总分满分为 **100分**：

**最终成绩＝天梯得分（70分）＋对打得分（30分）**

## 七、技术答辩

技术答辩以正式比赛提交的代码为准，**考察个人学习能力，ai使用能力，git使用情况，代码规范**
